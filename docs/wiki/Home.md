# Retinex GPU

One VapourSynth plugin offers exact, fast and fastest Retinex plus complete edge masks.
Choose an all-in-one CPU/CUDA build or a CPU-only build; both have the same API.

- [Benchmark results](Benchmark-results.md): all native paths and timing limits.
- [Image comparisons](Image-comparisons.md): five scenes, fixed display mapping and numerical differences.
- [Implementation](Implementation.md): algorithms, backend differences and compatibility exceptions.
- [Reproduce the tests](Reproduce-the-tests.md): pinned versions, commands and evidence.
